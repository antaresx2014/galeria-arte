# Skill de Identidad Visual y UI/UX ("Estética Museo")

## Principios Obligatorios
- **Paleta de Colores:**
  - Fondo primario: `#FAFAFA` (blanco hueso / `bg-gallery-50`)
  - Fondo secundario: `#FFFFFF` (blanco puro / `bg-white`)
  - Texto principal: `#111111` (carbón profundo / `text-gallery-900`)
  - Acentos de lujo: `#C5A059` (oro envejecido / bronce / `text-gold` / `border-gold`)
  - Vendido / Sold: `#B91C1C` / `#991B1B` discreto
- **Tipografía:**
  - `Playfair Display` para títulos, encabezados y citas de autor.
  - `Inter` para componentes de interfaz, especificaciones, botones y menús.
- **Restricción:** No usar colores chillones o estridentes. La atención visual debe residir 100% en las obras pictóricas.

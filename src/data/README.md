# Estructura de Datos y Referencias del Catálogo

Las obras del artista Tomás Odión siguen el estándar de inventario:
- Archivos de imagen: `/public/obras/OBRA-XXX-[slug].jpg`
- ID en código: `art-XXX` (ej. `art-001`, `art-002`, ..., `art-025`)

Todas las 25 obras están centralizadas en `artworks.ts`.
